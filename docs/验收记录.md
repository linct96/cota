## 验收时修复的问题

- 开发服务器地址的有无末尾 `/` 不一致导致合法 Main IPC 被拒绝：统一为 `new URL(...).href` 比较，仍校验主窗口和主 Frame。
- 原生关闭对话框结束后，末尾 ResizeObserver 回调与已关闭 PTY 竞争，产生 `终端已退出或正在关闭。` 伪错误：校验参数后忽略退出 / 清理中的 resize，补充既有生命周期测试。写入已退出会话仍拒绝。
- electron-builder 26.15.3 使用 `@electron/get` 的缓存模式，但原依赖解析到 3.0.0 导致 `Cannot read properties of undefined (reading 'ReadWrite')`：定向固定 3.1.0，未禁用校验或修改 node_modules。
