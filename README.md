# FAQ / 常见问题

## macOS 提示“无法验证 Cota.app 恶意软件”

如果在 macOS 上打开应用时提示“Apple无法验证 Cota.app 是否包含可能危害Mac安全或泄漏隐私的恶意软件”，请先确认应用来源可信，再在终端运行以下命令清除隔离标记：

```sh
sudo xattr -r -d com.apple.quarantine /Applications/Cota.app
```

> **注**：如果 `.app` 文件存放在其他路径（如未移动至 `/Applications`），请将命令中的路径替换为实际的 `Cota.app` 路径。

## 终端内如何输入多行文本

在支持的 CLI 中使用 `Shift+Enter` 换行，普通 `Enter` 保持原行为。终端使用固定版本的 xterm.js 6.1 beta，并启用原生 Kitty 键盘协议：Pi 等 CLI 协商后，由 xterm 区分 Shift+Enter 与普通回车；窗口重连时恢复协议状态与主屏 / 备用屏的模式栈。未启用 Kitty 协议的 Shell / CLI 仍使用 `Esc+Enter`，是否换行取决于其键绑定，不保证所有程序都支持。

输入法候选状态下，`Enter` / `Shift+Enter` 仅用于确认候选，不向终端发送回车；完成选词后，再按一次 `Shift+Enter` 换行。

## 如何浏览工作区文件

展开右侧工具面板，切换到文件页签。文件树以当前工作区目录为根，支持普通文件夹和 Git Worktree；按需展开目录，并独立保留各工作区的展开、选择及滚动位置。显示隐藏文件，但不展示 `.git` 管理项。

点击文件可在主区域只读预览，终端保持运行；预览标签和 Git Diff 共用一个位置，点击终端标签或“返回终端”即可返回。右键文件或目录可复制相对 / 绝对路径，或在系统文件管理器中定位。

展开目录和当前预览随磁盘变化刷新。监听不可用或目录被替换时会提示，点击刷新可重新连接。文本仅支持不超过 2 MiB 的 UTF-8 文件；二进制、超大文件和其他编码不提供预览。符号链接只显示目标，不跟随读取。单目录最多读取 10,000 项，同时最多监听 128 个已展开目录（含根目录）。首版不提供编辑、增删、重命名或搜索。
